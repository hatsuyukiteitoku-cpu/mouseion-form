# mouseion-form

ムーセイオン参加フォームの入力ページを置く公開リポジトリ。
ページは入力内容をどこにも送信せず、ブラウザの中だけで「Museに渡すテキスト」を作ります。

- `index.html` — 入力ページ本体。これ1枚で動き、外部のファイルを読み込みません。
- 通信をしないことは、ページ冒頭の `Content-Security-Policy` の指定でブラウザ自身に強制させています。
- 入力内容は保存しません。ページを閉じると消えます。
- このリポジトリには、個人の名前・鍵・記入済みのフォームを入れないでください。
- `en/index.html` — 英語版。`index.html` から `python3 tools/build_en.py` で作ります（手で直さないでください）。
- 日本語のページを直したら、`tools/build_en.py` の対応表に英語を足してから実行します。訳し忘れがあると、作成が止まって知らせます。
