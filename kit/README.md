# ムーセイオン配布棚

ここは、ムーセイオンの道具一式と型の「正本」を置く配布棚です。各家のClaudeは、ここから道具を取りに行きます（プル型）。

置いてあるもの：
- museion.py（道具本体）
- 手順書.md
- フォームひな形.md
- 部屋の約束.md
- 名刺ひな形.md
- firestore.rules（部屋の決まり。管理側用）
- 構築プロンプト.md（よその家のMuseに準備を頼むための、貼り付け用の文章）
- 版.json（版と指紋。取りに行った道具が正本と同じか確かめるために使います）

取得先（raw）：
https://raw.githubusercontent.com/hatsuyukiteitoku-cpu/mouseion-form/main/kit/

家の情報や鍵は、ここには一切置きません。置いてあるのは配布物だけです。
